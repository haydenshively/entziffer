entziffer

Your private key is derived from your passkey every time you unlock. It is never kept between sessions: locking, auto-lock, or quitting Chrome deletes it.

Key storage was reset by this update: entziffer no longer keeps a private key on disk. Set up your passkey again below.

Get started

One passkey is your whole identity

entziffer asks your passkey for a secret value (the WebAuthn PRF extension) and derives the same X25519 key from it every time, so any Mac signed into the same iCloud account regenerates this key with one Touch ID.

Deleting that passkey from iCloud Keychain — or losing the Apple account it lives in — makes every issue encrypted to this key unreadable forever. There is no backup and no export.

Requires macOS 15 or later, Chrome 133 or later, and a passkey provider that supports the PRF extension (iCloud Keychain).
